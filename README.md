# Session 3 — Gold dashboard

Course practice using synthetic sample data, not observed market evidence or investment advice.

Question: When did a selected country buy or sell gold in the sample, and what is its net total over a selected period?

Changes: country selector, year-range selector, monthly net-purchase bars with zero line and tonne units, selected-period total, matching table and CSV download. The controls apply only to the added country view; the original ranking remains the latest 12 months.

Run: `pip install -r requirements.txt` then `streamlit run app.py` (Python 3.12).

Original dashboard and sample data: https://dvn36104.github.io/session3/part-a.html
AI assistance: OpenAI Codex assisted with code changes, testing and deployment. The course starter design and data are retained and attributed above.
